About个人简介

I build local-first AI tools — software that runs on your own machine, keeps your data there, and still does real work. My projects span a Qt 6 / C++17 desktop AI assistant, an open-source email client distributed through PyPI, Homebrew and winget, and an MCP-based agent exposing 64 tools for campus affairs. I care about systems that are private by default, honest about what they actually do, and pleasant to use.

我做本地优先的 AI 工具：软件跑在你自己的机器上，数据留在你手里，同时真正能干活。 我的项目覆盖 Qt 6 / C++17 桌面 AI 助手、通过 PyPI / Homebrew / winget 分发的开源邮箱客户端， 以及一个对外暴露 64 个工具的 MCP 校园事务 agent。我在意三件事：默认保护隐私、不夸大实际能力、 用起来足够舒服。

Nmail

2026.09 – present至今

Local-first AI email client · Python, FastAPI, React · MIT · on PyPI, Homebrew & winget 本地优先 AI 邮箱客户端 · Python / FastAPI / React · MIT · 已上 PyPI、Homebrew 与 winget

  • Aggregates multiple mailboxes into one inbox with 20 preset providers (Gmail, Outlook, QQ, 163) and one-click OAuth.
  • 多账号聚合到单一收件箱，内置 Gmail / Outlook / QQ / 163 等 20 家预设服务商，支持一键 OAuth 授权。
  • An AI steward classifies, archives, drafts replies and compiles a daily digest — every write action requires explicit human approval and stays auditable and reversible.

  • Privacy by architecture: the service binds only to 127.0.0.1, with no account system, no telemetry and no cloud dependency; pointing it at Ollama or LM Studio enables fully offline inference.
  • 从架构上保证隐私：服务仅监听 127.0.0.1，无账号体系、无遥测、不依赖云端；指向 Ollama / LM Studio 即可完全离线推理。
  • Shipped to users through PyPI (nmail-app, 10 releases), Homebrew, winget and single-file executables for Windows, macOS and Linux.

LocalAIAssistant

2026.04 – present至今

Cross-platform desktop AI assistant · C++17, Qt 6, ONNX Runtime · MIT 跨平台桌面 AI 助手 · C++17 / Qt 6 / ONNX Runtime · MIT

  • A single binary offering both a GUI and a CLI, with SSE streaming output, persistent multi-session history, English/Chinese UI and light/dark/system themes.
  • 单一二进制同时提供 GUI 与 CLI，支持 SSE 流式输出、多会话历史持久化、中英双语界面与明暗 / 跟随系统主题。
  • Built a retrieval module supporting TXT/MD/PDF/DOCX import, automatic chunking and vectorisation, and HNSW approximate nearest-neighbour search — all embeddings computed locally through ONNX Runtime with no network access.
  • 实现检索模块：支持 TXT/MD/PDF/DOCX 导入、自动切分与向量化、HNSW 近似最近邻检索；嵌入向量全部经 ONNX Runtime 本地推理，无需联网。
  • Designed an agent loop (up to 10 iterations) that parses JSON task plans and executes them via native Qt file APIs rather than shell commands, with cross-platform shell detection where a shell is genuinely needed.
  • 设计 Agent 迭代循环（最多 10 轮）：解析 JSON 任务计划，优先用 Qt 原生文件 API 而非 shell 执行，仅在必要时才做跨平台 Shell 探测。
  • Implemented a three-tier command safety model — permanently blocked patterns, confirmed operations, and an allow-list — so that destructive commands cannot be reached by prompt injection alone.
  • 实现三级命令安全模型 —— 永久拦截、二次确认、白名单执行 —— 使破坏性命令无法仅凭提示注入被触发。
